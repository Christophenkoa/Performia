# Logo Performia - piste « Envol »

Un « P » blanc dans un carré arrondi bleu nuit, avec une flèche dorée qui monte : Performia et la progression de l'élève.

## Fichiers

| Fichier | Usage |
|---|---|
| `svg/performia-logo.svg` | Logo principal, sur fond clair |
| `svg/performia-logo-white.svg` | Logo sur fond bleu nuit ou sur photo sombre |
| `svg/performia-logo-tagline.svg` | Avec « Soutien scolaire · Répétitions », sur fond clair |
| `svg/performia-logo-tagline-white.svg` | Idem, sur fond foncé |
| `svg/performia-mark.svg` | Symbole seul (icône, avatar, tampon) |
| `svg/performia-mark-white.svg` | Symbole seul, version claire pour fond foncé |
| `png/performia-logo*@2x.png`, `@4x.png` | Versions PNG à fond transparent (documents, réseaux sociaux) |
| `png/performia-mark-512.png`, `-1024.png` | Photo de profil WhatsApp, Facebook, Instagram |
| `png/performia-mark-180.png` | Icône Apple (apple-touch-icon) |
| `png/performia-mark-192.png` | Icône Android / web app |
| `png/performia-mark-16.png`, `-32.png`, `-48.png`, `favicon.ico` | Favicon du site |

Les SVG n'ont besoin d'aucune police : le texte est converti en tracés. Pour l'impression, utiliser les SVG.

## Couleurs

| Nom | Hex | Usage |
|---|---|---|
| Bleu nuit | `#13294B` | Couleur principale, textes, fonds foncés |
| Or | `#D4A83A` | Flèche du logo, accents, boutons principaux (texte bleu nuit dessus) |
| Sable | `#F3EEDF` | Fonds doux, badges |
| Blanc | `#FFFFFF` | Fond principal |

L'or ne doit pas servir de couleur de texte sur fond blanc : le contraste est trop faible.

## Typographie

- Sora Bold : logo et titres
- DM Sans : textes courants et sous-titre du logo

Les deux sont sous licence SIL Open Font License (Google Fonts), utilisables librement, y compris en commercial.

## Règles d'utilisation

- Garder autour du logo un espace libre au moins égal à la moitié de la hauteur du symbole.
- Taille minimale : 24 px de haut pour le logo complet à l'écran, 16 px pour le symbole seul.
- Ne pas déformer, recolorer, faire pivoter ni ajouter d'ombre au logo.
- Sur photo, utiliser la version blanche uniquement si le fond est assez sombre.

## À vérifier avant impression

Vérifier que « Performia » est disponible comme marque au Cameroun (OAPI) avant tout dépôt ou impression en série.
